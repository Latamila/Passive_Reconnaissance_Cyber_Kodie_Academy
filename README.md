# Passive_Reconnaissance_Cyber_Kodie_Academy
Este projeto foi realizado como avaliação parcial para o curso de CyberSegurança da Kodie Academy.

Reconhecimento passivo (ou passive reconnaissance) é uma técnica de segurança cibernética usada para coletar informações sobre uma organização, sistema ou rede sem interagir diretamente ou enviar tráfego para a inffraestrutura do alvo. 

Como evita sondagens diretas ( como varreduras de portas ou requisições de serviços, essa técnica não gera logs (registros) em controles internos de segurança, como firewalls e sistemas de detecção de intrusão (IDS/IPS). Por isso, ela é praticamente indetectável. 

FERRAMENTAS COMUNS:

WHOIS E CONSULTAS DNS: Para descobrir a propriedade de domínios, intervalos de IPS  e servidos de email (registros MX).
SHODAN/CENSYS: Para buscar servidores, webcams e dispositivos IoT expostos ou mal configurados na internet. 
THEHARVESTER/SPIDERFOOT: Para automatizar a coleta de emails, nomes de funcionários, subdomains e credenciais vazadas. 
REGISTROS DE TRANSPARÊNCIA DE CERTIFICADOS (EX: crt.sh): Para encontrar certificados SSL/TLSemitidos, revelando subdomínios ocultos da empresa. 

POR QUE AS ORGANIZAÇÕES UTILIZAM?

HACKING ÉTICO E RED TEAMING: Para mapear a superficie de ataque externa de um cliente de forma segura antes de iniciar os testes invasivos. 

INTELIGÊNCIA DE AMEAÇAS (THREAT INTELLIGENCE): Para descobrir a "Shadow IT" (sistemas não homologados), credenciais expostas ou vazamentos de dados antes que criminosos os explorem. 

AUDITORIA DE DEFESA: Para que a própria empresa entenda quais informações confidenciais estão visíveis publicamente na internet e possa corrigi-las.
